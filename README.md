### <img src="https://cdn.jsdelivr.net/gh/Tarikul-Islam-Ankan/Animated-Fluent-Emojis/Emojis/People/Boy.png" width="28" /> О себе

Я backend-разработчик на **Go**. Мне нравится проектировать предсказуемые и устойчивые **REST API**, разбираться с реляционными базами данных и писать чистый, поддерживаемый код с понятной архитектурой.

* <img src="https://cdn.jsdelivr.net/gh/Tarikul-Islam-Ankan/Animated-Fluent-Emojis/Emojis/Objects/Laptop.png" width="20" /> **Фокус разработки:** Построение надёжной бизнес-логики, обработка ошибок, работа с JSON и оптимизация запросов к БД.
* <img src="https://cdn.jsdelivr.net/gh/Tarikul-Islam-Ankan/Animated-Fluent-Emojis/Emojis/Objects/Direct%20Hit.png" width="20" /> **Мой подход:** Писать понятную структуру пакетов (`pkg/`), покрывать ключевой функционал unit-тестами и не усложнять архитектуру без необходимости (KISS).
* <img src="https://cdn.jsdelivr.net/gh/Tarikul-Islam-Ankan/Animated-Fluent-Emojis/Emojis/Objects/Books.png" width="20" /> **Текущие задачи:** Погружение в глубокие нюансы конкурентности Go (goroutines/channels) и проектирование микросервисных архитектур.

#### <img src="https://cdn.jsdelivr.net/gh/Tarikul-Islam-Ankan/Animated-Fluent-Emojis/Emojis/Time/Calendar.png" width="22" /> [Task Scheduler](https://github.com/pyromeowww/task-scheduler)
*REST API сервис для автоматического планирования и расчёта повторения задач.*

* **Стек:** Go (`net/http`), SQLite (`modernc.org/sqlite`), Docker.
* **Инженерные решения:**
  * Разделил архитектуру на модули: изолировал логику работы с БД (`pkg/db`) и HTTP-обработчики (`pkg/server`).
  * Реализовал RESTful API эндпоинты с парсингом JSON-запросов и корректной обработкой HTTP-ошибок.
  * Написал кастомный алгоритм расчета правил повторения задач (дни, месяцы, года) с помощью пакета `time` и покрыл его тестами.
  * Спроектировал схему БД SQLite с индексацией по дате для быстрых выборок и автоматической инициализацией при старте.
  * Настроил конфигурацию сервиса через переменные окружения (`os.Getenv`).
