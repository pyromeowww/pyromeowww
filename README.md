### 🚀 Флагманский проект

#### 📅 [Task Scheduler](https://github.com/pyromeowww/task-scheduler)
*REST API сервис для автоматического планирования и расчёта повторения задач.*

* **Стек:** Go (`net/http`), SQLite (`modernc.org/sqlite`), Docker.
* **Инженерные решения:**
  * Реализовал RESTful API эндпоинты с парсингом JSON-запросов и корректной обработкой HTTP-ошибок.
  * Написал алгоритмическую логику вычисления дат повторения задач (дни, месяцы, года) на базе пакета `time`.
  * Спроектировал схему БД SQLite с индексацией по дате для быстрых выборок и миграцией при старте приложения.
  * Вынес конфигурацию сервиса в переменные окружения (`os.Getenv`) с фолбэками по умолчанию.
