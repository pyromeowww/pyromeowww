### 🚀 Ключевой проект

#### 📅 [Task Scheduler](https://github.com/pyromeowww/task-scheduler)
*REST API сервис для автоматического планирования и расчёта повторения задач.*

* **Стек:** Go, `net/http`, SQLite, Docker.
* **Что реализовано:**
  * Реализовал RESTful API эндпоинты с обработкой ошибок и валидацией JSON.
  * Написал кастомный алгоритм расчета правил повторения задач (дни, месяцы, года) с помощью пакета `time`.
  * Спроектировал схему БД SQLite с индексацией по датам и инициализацией таблиц при старте.
  * Настроил конфигурацию сервиса через переменные окружения (`os.Getenv`).
